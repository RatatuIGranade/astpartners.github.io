Изменения / Патч-ноты

Что нового в 0.0.4a

  • ConcordConnect Role Layer: разделение ADMIN_ROLE_IDS и CONCORD_CONNECT_IDS с каскадным доступом (админы видят всё).
  • Авто PTS: начисление за сообщения и каждую минуту голосовой активности на серверах партнёров.
  • Уровни и прогресс: пороги из LEVELS_JSON, показ «сколько осталось» в /partner_info.
  • Slash-автосинк: синхронизация команд с ASTERION, партнёрской гильдией и теми, что записаны в БД.
  • Стабильная БД: partners, partner_reps, partner_feedback.
  • Чистая UX ошибок: аккуратные эпфемерные ответы при отсутствии прав.
Команды

Slash-команды

Партнёр (ConCord) для CONCORD_CONNECT_IDS (админы тоже имеют доступ)
/partner_info name:"ServerName"
Статус партнёра: уровень, PTS, привязанный Guild ID, прогресс до следующего уровня.
/partner_me
Ваш профиль ConCord на текущем сервере.
/partner_reps name:"ServerName"
Список представителей партнёра.
/feedback message:"..." partner_name:"ServerName"
Отправить отзыв/репорт в ASTERION (#partners-feedback).
/status
Проверка состояния ConCord на этом сервере.
/partner_help
Список доступных партнёрских команд.
Администратор (ASTERION) для ADMIN_ROLE_IDS
/partner_add name:"ServerName" guild_id:"123"
Добавить партнёра и (опционально) привязать ID гильдии.
/partner_remove name:"ServerName"
Удалить партнёра и его представителей.
/partner_addrep name:"ServerName" user:@member
Добавить представителя партнёра (поддерживаются несколько человек).
/addpts partner:"ServerName" amount:100
Ручное начисление PTS партнёру.
/setlevel partner:"ServerName" level:2
Установить уровень партнёра.
/migrate
Проверить/обновить схему БД (безопасно вызывать повторно).
/partner_leaderboard
Топ партнёров по очкам (первые 10).
Права ролей

Модель доступа

Администраторы ASTERION — полный доступ к админским и партнёрским командам.
Админы партнёров (ConCord) — доступ только к информационным командам и фидбеку.

  • ADMIN_ROLE_IDS — /partner_add, /partner_remove, /partner_addrep, /addpts, /setlevel, /migrate, /partner_leaderboard + все партнёрские команды.
  • CONCORD_CONNECT_IDS — /partner_info, /partner_me, /partner_reps, /feedback, /status, /partner_help.
  • Администраторы автоматически проходят партнёрские проверки.
PTS и уровни

Система очков и прогресса

Пороговые значения задаются в LEVELS_JSON вашего .env. По умолчанию:

{ "1": 8000, "2": 20000, "3": 40000 }

В /partner_info отображаются текущий уровень, общий PTS и остаток до следующего уровня.

Голосовая активность

Как начисляются очки

  • Каждую минуту ConCord анализирует голосовые каналы партнёрских серверов.
  • Считает активных участников (боты не учитываются).
  • Начисляет PTS_PER_VC_MINUTE × участников партнёру.
  • Опционально: PTS за сообщения через PTS_PER_MESSAGE.

Все параметры конфигурируются через .env.

О ConcordConnect

Что это?

ConCordConnect — защищённый слой ролей и мост телеметрии для партнёров ASTERION. Обеспечивает наименьшие необходимые привилегии для партнёрских админов и полный контроль для ASTERION. Реализует авто-PTS, маршрутизацию фидбека и многосерверную синхронизацию команд.

.env параметры ключи окружения
  • DISCORD_TOKEN / TOKEN
  • GUILD_ID (ASTERION)
  • PARTNER_GUILD_ID
  • ADMIN_ROLE_IDS, CONCORD_CONNECT_IDS
  • PARTNERS_DB
  • PTS_PER_MESSAGE, PTS_PER_VC_MINUTE
  • LEVELS_JSON
